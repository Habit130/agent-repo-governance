# Governance adapts to outside changes and never controls them

habit updates harnesses and personal skills, and picks models, however habit likes. Governance sets no auto-update setting, update command or model pin.

A change that breaks a generator, install, machine-check or scenario run is a miss. It is fixed in this repository, with a fixture. The machine skill set is the system's own: once the generator v1 spec's deliveries build the install, the install manages it.

Decided in [How the generator and the install are verified before a version ships](https://github.com/Habit130/agent-repo-governance/issues/40).
