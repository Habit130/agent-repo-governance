# Governance adapts to outside changes and never controls them

habit updates harnesses and personal skills, and picks models, however habit likes. Governance sets no auto-update setting, update command or model pin.

From version 4, a start request names no model either: it states the work's difficulty ([ADR 0036](0036-difficulty-is-separate-from-the-risk-tier.md)), and habit chooses the model and effort. The one constraint left is the high Reviewer's vendor, different from every Builder's.

A change that breaks a generator, install, machine-check or scenario run is a miss. It is fixed in this repository, with a fixture. The machine skill set is the system's own: once the generator v1 spec's deliveries build the install, the install manages it.

Decided in [How the generator and the install are verified before a version ships](https://github.com/Habit130/agent-repo-governance/issues/40). The start-request sentence was added in [the version 4 planning round](https://github.com/Habit130/agent-repo-governance/issues/182).
