# A generator run is a Builder delivery that follows the role file it writes

Invoking the generator is habit's direct request, so each run that writes files is a high Builder delivery: an issue quoting habit's confirmation, a PR, the high reviews and habit's pinned merge.

From verification on, the run follows the Builder role file of the version it writes. The steps therefore exist in one place, even at Initialize. A copy of them inside the skill would drift.

Decided in [How the generator turns a repository's state into its governance](https://github.com/Habit130/agent-repo-governance/issues/17).
