# The generator runs only in Claude Code and OpenCode

A generator run hands habit more owner-account commands than any other session. So it runs only where the machine deny rules against calling habit's account alias and writing Actions secrets hold.

- **deepseekharness**: it has no such rules, so it is excluded.
- **Codex harness**: habit chose to keep the generator out of it.

Decided in [How the generator turns a repository's state into its governance](https://github.com/Habit130/agent-repo-governance/issues/17).
