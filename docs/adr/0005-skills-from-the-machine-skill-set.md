# Governance skills come from the machine skill set, and repositories commit no copies

Every skill that governance relies on is installed once on habit's machine and shared by every harness and every repository there. A governed repository names the skills it relies on and commits no copies of them. A session stops when one of them is missing.

The cost: every repository on a machine runs the same skill versions. The lag rule in ADR 0018 handles that. ADR 0020 records how the machine skill set reaches the machine.

Decided in [How one canonical policy reaches every harness](https://github.com/Habit130/agent-repo-governance/issues/16), as refined in [How the machine skill set is installed and updated](https://github.com/Habit130/agent-repo-governance/issues/26).
