# Planner, Builder and Reviewer are the governed roles

In a governed repository, habit is the Maintainer, and every agent session that writes holds one of three roles: Planner, Builder or Reviewer. A session started without a role is read-only. The risk tier comes from the change, not from a dispatching role, and dispatch is habit naming a ticket. The lightest process that runs reliably needs no dispatching session. These roles replace the Orchestration, Execution and Acceptance roles this repository runs under today, starting with this repository's first Initialize.

Decided in [Who does what: roles, sessions and habit's touchpoints](https://github.com/Habit130/agent-repo-governance/issues/11).
