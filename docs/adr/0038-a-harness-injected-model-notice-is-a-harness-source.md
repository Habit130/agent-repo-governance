# A model notice the harness injects is a harness source for session marks

From version 6, a session mark's model may come from a model notice that the harness itself injects into the session, beside the session's system prompt. The Antigravity CLI names the running model in such a notice, `USER_SETTINGS_CHANGE`, and not in the system prompt. The session reads the latest notice, and the source stays `from the harness`. A later notice naming a different model, as after habit switches models mid-session, adds a new mark before the session's next push or review, so the high Reviewer compares its vendor with every model that pushed. Text habit pastes, a start instruction and a configuration file never count as a notice. When neither source names the model, the session asks habit, as before.

This refines [ADR 0031](0031-session-marks-support-the-high-review-vendor-check.md), which took the model only from the system prompt. The alternative was to record every Antigravity CLI session's model `(as habit said)`. It needed no rule change, but it cost habit an answer in every session and rested on habit's recollection. The notice is the harness's own statement, as reliable as the system prompt against the honest mistakes the mark guards against. When habit decided, it was unverified whether the Antigravity CLI re-injects the notice after a mid-session switch. This repository's acceptance of the harness observes it.
